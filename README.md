# 序日 · 日常与计划

一个简洁的中文个人计划管理网页：左边收纳项目，右边安排每一天。适合在**单台设备、同一个浏览器**中使用，不需要账号、数据库、API 密钥或付费服务。

## 1. 第一次启动（适合编程初学者）

### 准备好 Node.js

1. 从 **https://nodejs.org/** 安装 Node.js 的 **LTS 长期支持版本**（需要 20 或以上版本）。保持安装时的默认选项即可。
2. 安装完成后，重新打开终端。Windows 可以使用「PowerShell」，macOS 使用「终端」。如果使用 VS Code，可在菜单中选择「终端 → 新建终端」。
3. 输入下面的命令并回车，出现版本号就说明安装成功：

   ```bash
   node --version
   ```

### 打开项目并启动

1. 如果还没下载项目，在 GitHub 仓库页面选择 **Code → Download ZIP**，然后解压。
2. 用 VS Code 打开解压后的 `CAPM` 文件夹，再选择「终端 → 新建终端」。**终端的当前目录应当包含 `package.json` 文件**。
3. 输入：

   ```bash
   npm start
   ```

   应用没有第三方运行依赖，**不需要先运行 `npm install`**。

4. 保持终端窗口打开，在浏览器地址栏输入：

   ```text
   http://127.0.0.1:3000
   ```

   看到「序日」和月历就启动成功了。**不要双击 `index.html` 启动**，请使用上面的命令和地址。

在当前云工作区，项目目录为 `/workspace/CAPM`，可以直接执行：

```bash
cd /workspace/CAPM
npm start
```

### 停止、重新启动与常见问题

- **停止服务**：在运行服务的终端按 `Ctrl+C`（macOS 也是这个按键组合）。
- **下次使用**：在同一个项目文件夹运行 `npm start`，使用同一个浏览器打开上面的地址。项目和日程不会因停止服务而删除。
- **提示找不到 `npm` / `node`**：确认已安装 Node.js，然后关闭并重新打开终端或 VS Code。
- **提示找不到 `package.json`**：终端不在项目目录。请在 VS Code 中打开包含该文件的文件夹，重新新建终端。
- **提示端口已被占用**：先看看应用是否已在另一个终端运行。如果确实需要换端口：`npm start -- --port 3001`，然后打开 `http://127.0.0.1:3001`。**不同端口是不同的数据空间**；要继续旧计划，应恢复原来的地址，或者先在旧地址导出备份，再到新地址导入。
- **页面打不开**：确认终端仍在运行、没有报错，并核对地址和端口。

## 2. 怎么使用

首次打开时，会放入「六级考试」「XX 项目提交」等少量示例，方便了解界面。可以直接修改，也可以点击页面底部「清除示例」。清除操作只移除尚未修改的示例，你新增或修改过的记录会保留。

### 管理项目

1. 点击左侧「新建一个项目」或「我的项目」旁的 **+**。
2. 填写项目名称、目标、截止日期（选填），选择一个颜色，再点击「创建项目」。
3. 点击左侧项目名称，可以看到目标、截止日期、完成进度和任务清单。
4. 点击右上角「编辑项目」修改信息；点击旁边的**归档图标**归档项目。
5. 归档项目会移到左侧「已归档」，可以随时查看和恢复。**已有任务与日历中的安排都会保留**，不会因为归档被删除。

### 给项目添加任务、安排时间

1. 打开项目，点击「添加任务」，填写要做的事情。
2. 可以先不勾选「安排到日历」，把它保存成待安排的任务。
3. 之后点击任务下方「安排时间」，选择日期、开始时间和结束时间，保存即可。
4. 这条任务会**自动出现在对应日期的时间表**中。点击任务旁的日期，可以直接跳到那一天。
5. 在项目清单或当天时间表里改名称、改时间、勾选完成，两边都会同步。删除其中一处的记录，也会从另一处一起移除，删除前会再次确认。

### 查看日历、管理独立日程

1. 点击左侧「日历计划」。右侧上方是月历，下方是所选日期的时间表。
2. 使用年月下拉框或左右箭头切换月份；点击「今天」回到当天。
3. 点击月历中的日期，再点击「添加日程」；顶部「新建日程」也会默认使用当前选中的日期。
4. 填写名称、日期和起止时间。「关联项目」选择「不关联项目 · 独立日程」，就可以单独记录运动、聚会等生活安排。
5. 勾选左侧小方框表示完成；点击**铅笔图标**编辑；点击**垃圾桶图标**删除。

结束时间必须晚于开始时间。跨天安排请拆成两条。未完成日程的时间有重叠时，会显示「时间有重叠」提示，但仍允许保存。日期与时间均按你设备的本地时区显示。

手机窄屏上，点击左上角的**三条横线**即可展开项目栏。页面右上角「?」和底部「使用指南」也可以随时查看帮助。弹窗支持按 `Esc` 关闭。

## 3. 自动保存与备份

每次成功修改都会立即保存到浏览器的 **localStorage**，刷新、关闭页面、关闭浏览器后重新打开都可以继续使用。应用不把你的计划上传到服务器。

请使用**同一设备、同一浏览器的同一用户资料、同一访问地址**。`localhost` 和 `127.0.0.1`、不同端口、隐私模式和其他浏览器，都属于不同的数据空间。不要把清除网站数据当作「刷新」；清除后本地记录也会被删除。建议定期备份。

### 导出备份

左下角「数据与备份」→「下载完整备份」。浏览器会下载一份 JSON 文件，包含全部项目（含已归档）、任务、日程、备注和完成状态。请妥善保管，它包含你的计划内容。

### 导入备份

1. 左下角「数据与备份」→「选择备份文件」，选择以前导出的 JSON 文件。
2. 文件通过校验后会显示项目和记录数量。支持最大 5 MB、500 个项目、10000 条任务 / 日程。
3. 选择导入方式：
   - **合并到当前计划**（默认）：保留其他记录。同一编号的记录以备份为准；重复导入不会生成副本。
   - **替换当前全部数据**：完全还原为备份的内容，当前其他记录会被覆盖。请先导出当前备份。
4. 点击「确认导入」。所有视图会立即更新。

损坏或不受支持的文件不会覆盖当前记录。浏览器存储写入失败时会提示，未保存的修改不会被当成成功。如果已保存的数据无法读取，应用会进入保护页面，让你先下载原始数据再决定是否重置，不会悄悄覆盖原记录。

同一个浏览器中打开多个标签页时，已保存的修改会同步。如果另一个标签页更新数据，正在编辑的弹窗会关闭并提示重新打开，避免旧表单覆盖新记录。

## 4. 开发与检查

运行环境：Node.js 20+。不需要构建，修改文件后刷新网页即可。`npm run dev` 与 `npm start` 等效。服务默认只监听本机 `127.0.0.1`。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网页入口 |
| `styles.css` | 中文界面、桌面与手机布局 |
| `src/app.js` | 页面、弹窗、项目 / 日程操作、自动保存与备份 |
| `src/model.js` | 统一数据模型、日期计算、数据校验与合并 |
| `server.mjs` | 仅使用 Node.js 自带模块的静态网页服务器 |
| `tests/model.test.mjs` | 数据和日期逻辑测试 |
| `tests/browser_test.py` | 真实浏览器完整流程检查 |

项目任务和日程存储在同一个 `items` 数组中，通过 `projectId` 与项目关联；未安排的项目任务日期和时间为 `null`。这样两种视图共用一条记录，不会各存一份造成不同步。

### 数据逻辑测试（无需额外安装）

```bash
npm test
```

应显示 10 项测试通过，涵盖日期边界、单一记录同步、非法时间、导入校验、备份合并、写入失败和安全清除示例。

### 浏览器流程测试（可选，供继续开发时使用）

应用运行不需要 Python；只有这组自动化检查需要 **Python 3.10+** 和 Playwright。在已安装 Python 的终端执行：

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium
npm run test:browser
```

Windows 如果使用的是 `python` 命令，将前两行的 `python3` 改为 `python`，最后一行使用 `python -u tests/browser_test.py`。

检查会自动启动一个随机端口的测试服务，使用独立的临时浏览器资料，不会修改日常使用的数据。它实际操作：创建 / 编辑项目、安排任务、跨年月切换、双向完成同步、独立日程增改删、刷新与关闭重开浏览器、归档恢复、备份导出和导入、多个标签页同步、390px 手机布局。结果截图保存在已被 Git 忽略的 `test-results/` 中。

本版本面向单台设备使用，不提供账号登录、云同步、通知提醒或多人协作。更换设备时，请通过 JSON 备份转移数据。
